## Features

- Device Monitoring
- Service / API Monitoring

### Window

- Borderless, Transparent
- Always on Top / Pin option
- Tray / Hidden
- Persistent settings, target, and profile
- Settings
- Change Opacity (soon)

### Widgets

- Clock
- General Metrics
  - CPU
  - RAM
  - Disk (not yet)
- Top Process (5)
- Developer Monitoring Widget
  - HTTP GET health
  - More soon

# Profiles

- Minimal
- Health Monitor
- Custom (not yet)
- More soon
